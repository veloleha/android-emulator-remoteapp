## 🔧 Решение проблемы с Android Studio

### Вариант 1: Переустановка Android Studio
1. Удалить текущую установку Android Studio
2. Установить Android Studio "для всех пользователей"
3. Убедиться, что SDK доступен всем пользователям

### Вариант 2: Настройка прав доступа
```powershell
# Дать права доступа всем пользователям к папке Android SDK:
icacls "C:\Users\[текущий_пользователь]\AppData\Local\Android" /grant "Users:(OI)(CI)F" /T
```

### Вариант 3: Копирование SDK
```powershell
# Скопировать SDK в общую папку:
robocopy "C:\Users\[пользователь]\AppData\Local\Android\Sdk" "C:\Android\Sdk" /E /COPYALL
```
